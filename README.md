# criativos-biblioteca

Catálogo de referências de edição audiovisual para o Graviton Video Editor (radar diário).

- `catalogo/referencias.json`: catálogo central (data, URL, técnica, categoria, nicho, dificuldade, status de implementação). IDs sequenciais `REF-XXXX`; verificar duplicatas por URL antes de adicionar.
- `relatorios/radar-AAAA-MM-DD.html`: relatório visual de cada dia.
