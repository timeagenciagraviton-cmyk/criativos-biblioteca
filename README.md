# criativos-biblioteca

Biblioteca de referências de edição audiovisual para o Graviton Video Editor, alimentada pelo Radar Diário de Criativos.

- `catalogo/referencias.json`: catálogo central (data, URL, técnica, categoria, nicho, dificuldade, status de implementação, observado × hipótese).
- `catalogo/referencias.csv`: versão em planilha, gerada por `python3 -I scripts/catalogo_csv.py` (também checa URLs duplicadas).
- `catalogo/fila-meta-ads-library.json`: anúncios da Meta Ads Library aguardando revisão visual manual.
- `relatorios/AAAA-MM-DD.md` e `.html`: relatório e galeria de cada dia.
